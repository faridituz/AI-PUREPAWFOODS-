## 地理来源、备份与回滚

## 本地复核与 P0-D

进入开发仓库，运行 `npm.cmd ci --ignore-scripts` 和 `npm.cmd run demo:field`，再打开 [地推演示](http://localhost:4311/field)。终端显示虚构账号与随机密码。admin.demo 可看全国，manager.demo 负责东区，sales.demo 及 west.demo 的客户范围不同。进入门店发现，选小行政区后导入候选，到核实池复核。用经理账号分配任务，再用销售账号从客户档案记录拜访或创建采购订单。验收进程结束时关闭，本地复核需自行启动。可运行 `npm.cmd test`、`npm.cmd run test:field:browser`、`npm.cmd run test:trade:browser` 重跑。

P0-D 获批后先完成 HTTPS 条件下的 Manifest、图标和 iOS/Android 安装路径，再做 Service Worker 静态缓存与敏感 API 排除、按账号隔离的离线草稿、断网状态、幂等补传/冲突处理、登录切换清理。最后在真机测安装、定位权限、网络恢复和订单重复防护。公共地图缓存和离线范围仍按供应商政策。P0-D 尚未启动。
