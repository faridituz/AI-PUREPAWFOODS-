## 6. 真正值得补充的能力

不建议现在补装通用 Excel、Word、PDF 或 Chrome Skill；这些能力已有覆盖。

1. **扫描件 OCR 工作流（条件性优先）**：如果常处理扫描合同、发票、图片表格，补足中文/多语言 OCR 引擎、版面分析、置信度与人工复核步骤。当前确认的是常规 OCR 依赖未检出；新增 Skill 本身不会带来 OCR 引擎。建议先验证已有服务是否可覆盖，再决定具体方案。
2. **个人业务流程 Skill（建议自建）**：将你的报表字段、文件命名、数据清洗规则、Word 版式和验收标准固化，减少重复提示。skill-creator 已有，可用它创建，无须再安装另一个 Skill 管理器。
3. **Office 实时连接（属于连接配置）**：如果需要操作正在打开的 Microsoft Excel/Word，优先建立受支持文档会话。安装更多文件处理 Skill 不能解决当前 0 会话问题。
4. **邮件/GitHub 集成（仅按业务需要）**：插件目录实际返回 Gmail 和 GitHub 均 installed=false。前者用于邮件检索和处理，后者用于仓库/PR/Issue 协作。它们是外部连接缺口，不是基础办公所必需，本次没有安装或发起连接。
