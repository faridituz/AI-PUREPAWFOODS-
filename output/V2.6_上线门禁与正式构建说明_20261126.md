## 二、门禁机制（`core/release-gate.mjs`）

门禁在构建开始时执行，任何一项失败即终止，不生成任何页面。当前实测（报告：`output/evidence/release-gate.json`）：

| 门禁 | 要求 | 当前 |
|---|---|---|
| langs-scope | 恰为 en/zh/ru/ar/uz/kk/ky/tg 八语，kaa/tr 关闭 | 通过 |
| langs-translation | 八语翻译全部达到 official | 阻断：zh/ar/kk/ky/tg 仍为草稿 |
| langs-public | 启用语言均已批准公开 | 通过 |
| content-draft | ui/forms/marketing/d/products/evidence 六个内容文件均非草稿 | 阻断：6 个仍标记 draft |
| products-approved | 产品数据整体获公开批准 | 阻断：publicApproved=false |
| products-verified | 7 个 SKU 数值已对照实物核验 | 阻断：7 个全部 pending-physical |
| products-conflicts | 无未决数据冲突 | 阻断：small-dog-beef 喂食表 |
| content-log | 每条内容变更 approvalStatus=approved | 阻断：8 条待批准 |
| evidence-required | requiredForLaunch 证据全部 verified | 阻断：8 项（数据稿、喂食冲突、营养基准、生产地址、清真证书、产品实拍、经销政策、法律文本） |
| forms-endpoint | 已配置并批准 HTTPS 正式接收端 | 阻断：未配置（当前只有本地模拟 API） |
| draft-copy | 页面无 prototype/原型/模拟 提示 | 阻断：8 语均含原型角标 |
| claims-scan | 无未证实认证/检测宣称 | 通过 |
| origin | HTTPS 且非 localhost/示例域 | 通过（测试参数） |

**9 项阻断全部是“内容/证据/审批”问题，不是代码或版式问题。** 补齐材料并逐项批准后，门禁会自动放行，无需改代码。

## 三、正式构建产物边界（门禁通过后）

`output/release/` 将只包含：

```
release/
  d/
    index.html            8 个语言首页
    cat/ dog/ brand/ partners/ contact/ ...
    product/<7 SKU>/      8 语 × 7 SKU
    errors/<8 语>.html    本地化 404
    assets/{base.css, theme.css, logo.png, form.js}
    sitemap.xml           仅 8 种正式语言的 104 个 URL
    robots.txt            Allow + Sitemap
    build.json
```

明确排除：

- A/B/C 三个原型目录、原型总览页、测试接口与测试页面；
- `mock-leads` 数据、限流/压测脚本、QA 脚本与证据 JSON；
- 内部审核报告（`output/V2.6_*.md` 等）；
- 任何 `noindex`、`data-prototype`、原型角标、模拟线索提示；
- `kaa`/`tr` 页面与链接、旧语言 URL；
- 未批准的产品数值、未批准的翻译、未批准的营销文案。

`qa-release.mjs` 用于构建后复核：对原型 D 实测 11 项中 7 项失败（noindex、data-prototype、原型角标、原型字样、mock 文案、localhost、robots 禁止抓取），证明它确实能识别发布包泄漏；正式构建通过后再跑应为 11/11。

## 四、表单与线索边界

- 原型表单只提交到本地模拟 API（`/api/lead`，`serve.mjs` 提供），线索写入 `data/mock-leads/`，不进入真实 CRM，不发送客户消息。
- 正式构建要求 `forms.json → meta.productionEndpoint` 为已获批的 HTTPS 地址且 `endpointApproved=true`；未配置前门禁阻断。
- 即使配置了接收端，启用真实 CRM 写入仍需老板单独批准；本阶段不连接任何真实 CRM。

## 五、发布流程（未来执行顺序）

1. 老板补齐材料：产品实拍与营养标签、清真证书、经销政策、法律文本、生产地址确认、小犬喂食确认、母语审校。
