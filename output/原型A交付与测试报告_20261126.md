## 一、架构（8 语统一，不建 8 套站）

```
content/site.json   8 语真实文案（从线上 HTML 提取，逐字段核对）
content/ui.json     8 语界面词条 + 语言名称 + 文字方向
build-a.mjs         单一生成器：13 类页面 × 8 语 = 104 页
styles/a.css        设计系统（方案 A：国际高端）
serve.mjs           本地预览（Content-Language、缓存头演示）
```

- 统一产品数据源：7 个系列、19 个规格在生成器中只维护一份，按语言引用文案；营养/配料数值不随语言分叉。
- 每种语言输出独立网址：`/a/{lang}/`、`/a/{lang}/cat/`、`/a/{lang}/dog/`、`/a/{lang}/product/{slug}/`、`/brand/`、`/partners/`、`/contact/`。
- 访客只下载当前语言页面（对比现有站：8 语全部塞进同一 HTML）。
- 语言切换为普通链接，切换后停留在同一页面/同一产品，不跳首页、不丢浏览位置。
- 生成器可切换输出目录与域名（`--out`、`--origin`），后续方案 B/C 复用同一内容源。

## 二、已实现的 8 语 SEO 与可访问性

- 每页 `<html lang="xx" dir="ltr|rtl">`，阿拉伯语整站 RTL 布局。
- 每页 8 个 `hreflang` + `x-default` + 自身 `canonical`（绝对地址由构建参数注入）。
- 页面标题、描述按语言/产品生成；图片有 alt；导航有 `aria-current`；提供跳转主内容链接。
- 原型构建默认 `noindex, nofollow` + `robots.txt Disallow: /`，防止测试站被搜索引擎收录。
- 自动检查：非中文页面不得出现中日韩字符（防止中文串入对客文案）。

## 四、缓存与安全策略

原型（本地/测试）：
- HTML `Cache-Control: no-cache`，资源 `max-age=1y, immutable`；
- 全站 `X-Robots-Tag: noindex`、`robots.txt` 全禁。

生产方案（待选定后实施，不改变现有站）：
- 每语言独立 URL + 正确 `Content-Language`，避免跨语言缓存串页；
- HTML 短缓存（如 5–15 分钟）+ ETag/Last-Modified，发布后主动清 Cloudflare 缓存，替代当前 31 天 HTML 缓存；
- 静态资源长缓存 + 文件名指纹；
- 管理后台、表单提交、客户个人数据一律不进公共缓存；
- 图片转 WebP/AVIF + 响应式 `srcset` + 懒加载；视频用封面图，不自动播放。
