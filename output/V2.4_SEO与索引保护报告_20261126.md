## 二、hreflang 实例（B 原型俄语产品页）

```html
<link rel="alternate" hreflang="en" href="…/b/en/product/kitten-chicken/">
<link rel="alternate" hreflang="zh" href="…/b/zh/product/kitten-chicken/">
<link rel="alternate" hreflang="ru" href="…/b/ru/product/kitten-chicken/">
<link rel="alternate" hreflang="ar" href="…/b/ar/product/kitten-chicken/">
<link rel="alternate" hreflang="uz" href="…/b/uz/product/kitten-chicken/">
<link rel="alternate" hreflang="kk" href="…/b/kk/product/kitten-chicken/">
<link rel="alternate" hreflang="ky" href="…/b/ky/product/kitten-chicken/">
<link rel="alternate" hreflang="tg" href="…/b/tg/product/kitten-chicken/">
<link rel="alternate" hreflang="x-default" href="…/b/en/product/kitten-chicken/">
<link rel="canonical" href="…/b/ru/product/kitten-chicken/">
```

- 语言代码使用 ISO 639-1；`x-default` 指向英文。
- 切换语言保持当前产品页（`qa-layout.mjs` 交互断言通过）。
- 阿拉伯语页面 `<html lang="ar" dir="rtl">`，电话/SKU 数字保持 LTR。

## 四、测试环境 vs 生产环境的索引保护

| 项目 | 测试构建（默认） | 生产构建（`--index`） |
| :--- | :--- | :--- |
| 页面 meta | `<meta name="robots" content="noindex, nofollow">` | 无 noindex |
| robots.txt | `User-agent: *` / `Disallow: /` | `User-agent: *` / `Allow: /` / `Sitemap: {origin}/{theme}/sitemap.xml` |
| 访问范围 | 仅 `localhost`，未暴露公网 | 未部署 |
| 入口页 | 原型选择页永远 noindex | 不上传入口页（仅部署选定主题） |
| 构建清单 | `build.json` 记录 `noindex:true` | `noindex:false` |
| 自查命令 | `node qa-multilingual.mjs` | `node qa-multilingual.mjs --prod --origin https://正式域名` |

**防配置串味**：
1. 索引开关只有一个来源 `NOINDEX = !args.includes("--index")`，meta 与 robots 共用该布尔值（BUG-11 修复点）。
2. 域名由构建参数 `--origin` 一次性写入 canonical/hreflang/sitemap，运行时不再拼接。
3. 三套主题输出到独立目录（`/a`、`/b`、`/c`），互不覆盖。
4. 生产检查脚本支持 `--base`（抓取地址）与 `--origin`（公开域名）分离，可在本机验证生产产物而不误连正式站。
5. 根入口预览页固定 noindex，避免误收录原型选择页。

## 五、自动上线前检查机制

`qa-multilingual.mjs` 任一项失败进程返回 2，可直接作为 CI/上线闸门。覆盖：

1. 每页 9 条 hreflang 数量、目标属于已构建 104 页、8 语言互相一致；
2. canonical 自引用且使用公开域名；
3. sitemap 与构建集合完全相等，所有 URL 可访问；
4. 测试模式要求 noindex + robots 全禁；生产模式要求无 noindex + robots 放行；
5. `<html lang dir>`、标题/描述语言、表单提示语言；
6. 本地化 404（真实 404 状态 + 对应语言标题）；
7. 封闭功能扫描（无购物车/价格/门店定位）；
8. CSP 响应头存在。

生产模式实跑记录（2026-11-26）：`--base http://localhost:4176 --origin https://purepawfoods.com --prod` → **1,895 项，失败 0**。
