## 一、15 项检查定义

| 编号 | 检查项 | 判断标准 |
| :--- | :--- | :--- |
| C1 | 首屏 3 秒识别 | 不滚动能否看懂“卖什么、给谁、在哪个国家” |
| C2 | 品牌身份可信 | 公司全称、地址、产地、认证是否可见 |
| C3 | 产品线可扫读 | 能否在 1 屏内分清猫/狗、幼年/全年龄 |
| C4 | 产品信息深度 | 成分、营养分析、喂食量、规格是否足够决策 |
| C5 | 价格/购买不误导 | 无价格时是否明确“线上未开售”，不放假购物车 |
| C6 | 关键差异化 | 清真认证、乌兹别克本地生产是否突出 |
| C7 | 联系方式零思考 | WhatsApp/电话/邮箱是否 1 次点击可达 |
| C8 | 表单摩擦 | 字段数量、必填/可选标注、占位语言、隐私同意 |
| C9 | 移动端 CTA | 390px 下主按钮是否在首屏拇指区、可点 |
| C10 | 语言与方向 | 语言、`lang/dir`、阿拉伯语 RTL 是否正确 |
| C11 | 社会证明 | 门店、客户评价、案例、合作品牌等第三方证据 |
| C12 | 风险逆转 | 回复时效、隐私说明、不夸大承诺 |
| C13 | 真实稀缺/紧迫 | 不使用倒计时、假库存、假涨价 |
| C14 | CTA 文案 | 行动导向，而非“了解更多”式空话 |
| C15 | 综合留资意愿 | 该角色是否愿意留下电话或发消息（0–10 分另列） |

评分符号：✓ 满足　△ 部分满足/需多一步　✗ 不满足。
