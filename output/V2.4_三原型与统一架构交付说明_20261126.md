# PUREPAW 三套原型与统一架构交付说明（V2.4 第 VI 节）

日期：2026-11-26　基线提交：7142587　本地预览：`http://localhost:4173/`

## 一、结论

三套可运行原型已生成，**共用同一套内容、组件、表单、模拟 API、SEO 与测试框架**，只在视觉、信息层级、营销表达与用户旅程上不同。全部为纯静态零依赖构建，每套 8 语言 × 13 页 = 104 页，三套共 312 页。全部 noindex、只在本机预览，未触碰正式网站。

## 三、三套原型的差异（只在这四处）

| 维度 | A 国际高端 | B 信任转化 | C 品牌招商 |
| :--- | :--- | :--- | :--- |
| 视觉 | 森林绿 + 米白，衬线大标题，克制留白 | 暖沙 + 陶土色，卡片化，表单描边强调 | 深海军蓝 + 铜金，编辑排版，细边框 |
| 信息层级 | 品牌理念 → 品类 → 产品 | 信任条 → 三步下单 → 产品 → 咨询表单 | 品牌故事 → 产品 → 招商权益 + 招商表单 |
| 用户旅程 | 了解品牌 → 浏览产品 → WhatsApp/电话 | 建立信任 → 消除选择困难 → 留资 | 看品牌 → 看产品 → 申请经销 |
| 营销重点 | 自然、关怀、国际感 | 清真认证、本地生产、完整成分、快速回复 | 批发价目、店员物料、全境配送 |

其余全部一致：产品数据、文案来源、8 语言、图片、组件、表单字段与校验、模拟 API、SEO 模块、安全头、测试脚本。

## 四、共享架构（代码位置）

```
src/website-v2/
  content/
    languages.json   语言清单（enabled 开关，8 启用 + 2 候选停用）
    site.json        8 语言真实产品/品牌文案（从线上抽取）
    ui.json          导航、按钮、页脚等 8 语言 UI 文案
    forms.json       表单标签/错误/隐私/成功文案（8 语言）
    marketing.json   B/C 专用营销段落（8 语言）
    errors.json      8 语言 404 文案
  core/
    content.mjs      统一加载 + 完整性校验（缺语言/缺产品直接构建失败）
    html.mjs         共享布局、页头页脚、语言切换、hreflang/canonical、产品卡、联系区、JSON-LD
    forms.mjs        共享表单组件（咨询/招商两种字段集）
    validate.mjs     客户端/服务端共用的校验函数（同一份源码）
    pages.mjs        共享页面生成器（三套主题复用）
  styles/
    base.css         公共设计系统与组件样式
    theme-a/b/c.css  仅设计令牌与少量主题修饰
  build.mjs          一次构建三套（--theme 可单套）
  serve.mjs          静态服务 + 模拟 API + 安全头 + 本地化 404
  qa-layout.mjs      布局/SEO/交互自动化（552 组合）
  qa-multilingual.mjs 多语言/规格/封闭功能/双向 hreflang（1,895 项）
  qa-forms.mjs       表单安全与端到端提交（44 项）
  stress.mjs         本机隔离压测（10/50/100 并发等）
  perf.mjs           模拟 3G 实验室性能
  shot.mjs           定点截图工具
```

构建：`node src/website-v2/build.mjs`（输出 `output/prototypes/{a,b,c}`，含 sitemap、robots、build.json、每语言 404、三套入口页）。

## 五、每页内容结构（13 页/语言）

首页、猫粮（3 款）、狗粮（4 款）、品牌、合作伙伴（招商表单）、联系（咨询表单）、7 个产品详情页。
产品顺序与数据来自线上真实内容，未编造价格、库存、门店、评价、认证编号。

## 六、表单与模拟 API（明确标注）

- 咨询表单：姓名、电话、邮箱（选填）、城市、意向产品、留言、隐私勾选。
- 招商表单：公司/店铺、姓名、电话、邮箱、城市、业务类型、月采购量、留言、隐私勾选。
- 提交到 `POST /api/lead` 本地模拟 API：写入 `data/mock-leads/leads.jsonl`（脱敏），**不连接真实 CRM、不发送任何客户消息**。
- 页面与成功提示均明确写“原型演示/本地模拟，不是真实销售线索”。
- 校验、限流、幂等、CSRF、XSS、日志脱敏详见《V2.4_表单安全测试报告》。

## 七、SEO / 安全基线

- 每页 9 条 hreflang（8 语言 + x-default）、canonical 自引用、`<html lang dir>` 正确；ar 为 RTL。
- 8 语言 sitemap 各 104 条 URL；robots 全站 Disallow（测试环境）；HTML `no-cache`，静态资源 1 年 immutable + ETag。
- 响应头：CSP、nosniff、Referrer-Policy、X-Frame-Options、X-Robots-Tag noindex。
- 无购物车/结账/价格/门店定位器/后台链接；自动化扫描 120 项全部通过。
