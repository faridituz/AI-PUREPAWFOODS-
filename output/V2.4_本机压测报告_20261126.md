# PUREPAW 本机隔离压测报告（V2.4 第 IX 节）

日期：2026-11-26　脚本：`src/website-v2/stress.mjs`　原始数据：`output/evidence/stress-report.json`
**重要声明：以下全部为本机隔离端口测试结果，不代表 GoDaddy 生产主机实际承载能力；未对正式网站施加任何压力测试。**

## 一、结论

- 三套原型的静态架构在本机（4 核 i5-6300U / 7.4 GB / Node v26）**10、50、100 并发全部 0 请求失败**。
- 单语言英文首页：1,471 RPS（c=10）→ 1,887 RPS（c=50）→ **2,021 RPS（c=100）**；P95 从 15 ms 升到 71.9 ms，P99 101 ms。
- 混合 8 语言并行与单语言吞吐差距在 10% 内，**无跨语言缓存污染**（Content-Language 与请求语言不一致次数 = 0）。
- 60 秒长跑内存基线 98.5 MB、峰值 98.5 MB、结束后 94.6 MB，**无增长迹象（−3.9 MB）**。
- 表单 POST 在 STRESS 模式（放开限流）下 804.8 RPS，0 失败；正常模式的限流已单独验证（第 6 次起 429）。

## 五、缓存与失效

| 项目 | 实测 |
| :--- | :--- |
| HTML 缓存头 | `no-cache`（每次回源校验，适合频繁更新的营销页） |
| 静态资源缓存头 | `public, max-age=31536000, immutable` |
| 资源 ETag | `W/"3fcf-6b081307"` |
| `If-None-Match` 复验 | **304**（不重复传输） |
| 修改文件后 ETag | 变为 `W/"3fee-6b081661"`，内容更新可被识别 |
| 冷启动资源（新进程） | 1,035 RPS，P95 87.4 ms（首次读盘 + 进程启动） |

风险提示：当前静态资源**未做内容指纹（hash 文件名）**。上线后若同名覆盖 CSS/JS，浏览器最长 1 年不更新；建议部署时给资源加 hash 或使用版本目录。此为已知待改进项。

## 六、内存与泄漏

- 长跑 60 s（c=20，混合 8 语言，约 10.9 万请求）：RSS 基线 98.5 MB → 峰值 98.5 MB → 结束后 94.6 MB。
- 表单测试写入 400 条模拟线索，`data/mock-leads` 从 0.02 MB 增至 0.14 MB；原型产物目录 11.7 MB 不变。
- Node 未开启强制 GC，RSS 回落有滞后；本次无增长迹象，但**未做小时级长跑**，不能宣称“绝对无泄漏”。

## 七、未验证 / 边界

- 以上为本机回环，**不含公网 RTT、TLS、CDN、GoDaddy 共享主机限制**；生产承载能力**未验证**。
- 未测试 HTTPS、HTTP/2、Keep-Alive 长连接被中间设备断开的情况。
- 未测试表单真实 CRM 写入（禁止）、真实短信/WhatsApp 通知。
- 未测试数据库（原型无数据库）；Cloudflare 缓存规则未参与。
- 本机 4 核 7.4 GB，不能外推为生产容量；若上线需要，应在批准后另建隔离测试环境复测。
