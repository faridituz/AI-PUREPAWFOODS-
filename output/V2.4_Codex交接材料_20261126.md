## 一、一分钟上手

```bash
git pull
node -v                       # 本机验证 v26.13.1；要求 ≥ 22（ESM + WebSocket 全局）
node src/website-v2/build.mjs --origin http://localhost:4173
node src/website-v2/serve.mjs          # 默认 4173，根目录 output/prototypes
# 另开终端
node src/website-v2/qa-layout.mjs --shot
node src/website-v2/qa-multilingual.mjs
node src/website-v2/qa-forms.mjs
node src/website-v2/stress.mjs
node src/website-v2/perf.mjs
```

- 预览：`http://localhost:4173/`（入口页）、`/a|b|c/{lang}/`
- 构建默认 `noindex`；只有加 `--index` 才允许索引（生产前保持关闭）。
- 压测必须用 `STRESS=1` 启动的**独立端口**（stress.mjs 自己起 4180/4181），不要对 4173 的日常预览压。
- `qa-forms.mjs` 自带测试服务（4174 API、4175 UI，均 STRESS），不依赖 4173；跑完自行退出。
- Chrome 路径可用 `CHROME_PATH` 覆盖；Windows 默认 `C:/Program Files/Google/Chrome/Application/chrome.exe`。

## 三、必须遵守的架构约束

1. **单一内容源**：三原型共用 `content/`、`core/`、`assets/`、`styles/base.css`；主题差异只允许在 `theme-*.css` 与 `pages.mjs` 的首页旅程。
2. **语言可配置**：新增语言 = 在 5 个 JSON 里补文案 + `languages.json` 开 `enabled`；`enabled:false` 不生成页面。禁止删除已有 8 语言，禁止未经批准公开新语言。
3. **SEO 基准**：每页 8 语言 hreflang + x-default + canonical；默认 `noindex`；`/errors/{lang}.html` 返回真实 404。
4. **表单安全**：同源校验、`application/json`、16 KB 上限、限流、蜜罐、幂等、服务端校验、日志脱敏；`validateLead` 不得只改前端。
5. **mock 边界**：`/api/lead` 只写 `data/mock-leads/leads.jsonl`；不得接真实 CRM、不得发真实客户消息；UI 必须保留“非真实 CRM”的说明。
6. **密钥**：任何 Token/密码走 `.env` + `process.env`，禁止写入代码与文档。
7. **路径**：所有写入限制在项目根目录；不要写桌面/临时目录。

## 五、已知坑（错题本摘要）

- **Windows 下服务占用输出目录**：重建前若报 EBUSY，先停 `serve.mjs`；不要 `taskkill //IM node.exe`，只杀指定 PID。
- **限流污染测试**：功能测试用 `STRESS=1`；限流单独起全新进程验证，否则前序非法请求会吃掉额度。
- **Chrome `--window-size` 小于 500 会误报横向溢出**：移动端尺寸一律用 CDP `Emulation.setDeviceMetricsOverride`。
- **多语言断言**：邮箱/URL 占位符不算“未翻译”；阿语电话断言用 `/\+998/`。
- **构建路径**：页面必须写到 `{theme}/{lang}/...`，不要再套主题目录。
