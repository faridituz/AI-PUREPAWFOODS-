## 一、三种部署方案对比

| 项目 | 方案 1：维持现状（WordPress） | 方案 2：混合（WP 保留 + 静态原型上子域） | 方案 3：全量静态切换 |
| :--- | :--- | :--- | :--- |
| 额外月费 | 现有套餐（金额未核对） | 0（Cloudflare Pages 免费额度 / GoDaddy 静态托管） | 可能省去 WP 托管费，需重新选托管 |
| 迁移工作量 | 0 | 低：构建 + 上传 + 子域解析 | 中高：全站切换、重定向、SEO 交接 |
| 安全面 | PHP + 插件 + 主题，需持续更新 | WP 保持原状；静态站无数据库、无登录 | 无 PHP/数据库，攻击面最小 |
| 性能 | 依赖 PHP 与插件；线上实测 LCP 996 ms | 本机本地 LCP 600–840 ms（3G 模拟） | 同方案 2 |
| 内容编辑 | WordPress 后台 | WP 管旧站，静态站需重新构建 | 需 Git/Markdown 流程，非技术同事不友好 |
| 语言管理 | 依赖 WP 多语言插件 | `languages.json` 开关，构建时生成 | 同方案 2 |
| 回滚 | 不需要 | 删除子域即可，主站零风险 | 需保留旧站快照与 DNS 回滚 |
| 上线审批点 | — | DNS 新增子域（需批准） | 首页替换 + DNS（需批准） |
| 适合阶段 | 现在 | **建议先做** | 验证 2–4 周后再评估 |

结论：**先混合、后切换**。用子域（如 `new.purepawfoods.com`）上线真实静态预览，不触碰主站；收集真实访问与转化后再决定是否整体切换。当前未申请 DNS 修改，也未购买任何服务。

## 三、设计建议

### 3.1 推荐主站：原型 B（信任与咨询转化型）

理由：
1. 首屏 CTA 直接问“不知道选哪款？”，匹配多数首次购买者的真实心理（审计 P1/P2/P4 留资意愿最高）。
2. 首页即含引导表单 + 信任条（清真、乌兹别克制造、成分透明），减少一次跳转。
3. 暖色系更亲和，移动端信息节奏清楚；8 语言与 RTL 已通过全部检查。
4. 同一构建可切换到 C 的招商页，无需第二套后台。

### 3.2 招商入口：原型 C 的招商页

- `/partners/` 使用 C 的海军蓝+金铜视觉与内嵌经销商表单，作为独立投放落地页；
- 与 B 共享产品数据、表单组件、mock API、SEO 模块，不新建后端；
- 需要业务先提供起订量、区域、账期、回复时效，否则保持现状文案，不编造。

### 3.3 品牌故事：原型 A

- 作为 `/brand/` 或品牌 campaign 页保留；高端留白与编辑排版适合展会、招商 PPT、Instagram 引流；
- 不作为默认成交页（无表单、无社会证明）。

### 3.4 共同待补（三套都受影响）

- 真实营养表、喂食量、包装实拍；
- 门店/客户评价（需授权）；
- 清真证书图与编号；
- 8 语言母语审校；
- 表单回复时效与隐私政策法务文本。

## 五、风险与止损

- 静态站失去 WP 可视化编辑：若市场团队频繁改文案，需保留“改内容→重新构建”的流程或引入轻量 CMS。
- 8 语言维护成本主要在翻译，不在服务器；不要因语言多而升级主机（本机压测 1/6/8 语言差异 <10%）。
- 若直接切换主域而无 301 映射，会损失现有 SEO；切换前必须导出旧 URL 清单做重定向。
- 所有上线动作在获得明确批准前不执行；当前仅本地构建与本地测试。
