## 二、120 组合的定义与本次复测

原“120 组合”= 8 语言 × 5 页面（首页、猫粮、产品详情、合作伙伴、联系）× 3 断点（390 / 768 / 1440）。
本次额外要求 320 / 360 / 412 / 1920：只对关键页（首页 + 产品页）加测，避免无意义膨胀。

每套原型实际检查：120（核心）+ 64（4 个补充宽度 × 2 页 × 8 语言）= **184**；三套共 **552**。

复测逐项确认了以下“可能造假”的点：

| 质疑点 | 本次做法 | 结果 |
| :--- | :--- | :--- |
| 是否跳过测试 | 三套全量循环，无 skip；控制台逐套打印组合数 184 | 552/552 执行 |
| 是否只加载不交互 | 额外做“语言切换保持当前产品页”“浏览器后退”交互抽检 | 6/6 通过 |
| 是否忽略异常 | 任何一项问题即计入 failures，进程返回码非 0 | 0 failures |
| 是否有重复截图 | 截图按 主题-页面-语言-宽度 命名，无重复文件名 | 12 + 4 张 |
| 是否把未实现功能测成通过 | 已实现功能才断言（表单仅在联系/合作/首页 B、C 出现）；A 首页无表单也做了“不应出现”的反向断言 | 通过 |
| 结论是否可复现 | 命令、JSON 日志、截图、Git 版本一并保留 | 见下 |

补充说明：
- **字体字形**：用 canvas 逐字符宽度与 U+FFFD 宽度对比的启发式检查，未发现疑似缺字字符；这是启发式，不等于像素级人工验收（仍建议真机看阿语/西里尔字形）。
- **语义一致性**：机器只能校验结构、数字与脚本，不能判断译文是否“听着像母语”。该项仍为未验证，需母语人员。
- **营养数值**：线上未公开营养保证值，原型未编造；只校验了净重（1.5/3/10 kg）与名称内百分比（51%/40%/48%）在各语言一致。

## 五、SEO 上线前自动检查机制（已具备）

`qa-multilingual.mjs` 即为“上线前自检”：任何一项失败进程返回 2。覆盖：
1. 9 条 hreflang（8 语言 + x-default）存在且指向已构建 URL；
2. canonical 自引用；
3. hreflang 双向一致（8 语言互相指向）；
4. sitemap 与构建集合完全相等，且 104 条 URL 全部 200；
5. robots 测试环境全站禁止收录；
6. 每页 `<html lang dir>` 正确；
7. 本地化 404。
上线时把 `build.mjs` 的 `--index` 打开、robots 改为放行、加 HSTS/正式域名，再跑同一脚本（预期 noindex/robots 两项需按环境切换断言）。**未执行上线操作。**

## 七、本轮发现并修复的问题

| 编号 | 现象 | 根因 | 修复 |
| :--- | :--- | :--- | :--- |
| BUG-01 | 首次构建页面全 404 | 输出目录多套了一层主题名（`a/a/en`） | 页面与资源路径改为 `output/prototypes/{theme}/{lang}` |
| BUG-02 | 联系/合作页重复大标题与联系区 | 模板残留 contact band | 联系页、合作页移除重复区块 |
| BUG-03 | 表单测试 6 项失败 | 限流计入非法请求，前序校验请求把额度用光 | 功能测试用 STRESS 模式，限流单独用全新进程验证 |
| BUG-04 | 线索文件缺 lang/source | 只保存了校验后的字段 | 合并语言、来源、页面、utm 后落库 |
| BUG-05 | 蜜罐命中返回 400 | 先判 `!ok` 后判 spam | 调整顺序，蜜罐返回假成功且不落库 |
| BUG-06 | 404 只有英文纯文本 | 未做多语言错误页 | 每语言生成 404 页，服务端按路径语言返回 404 HTML |
| BUG-07 | 多语言测试误报邮箱占位符“未翻译” | 断言过严 | 排除邮箱/URL 形式占位符 |
| BUG-08 | 阿语电话 LTR 断言误报 | 正则转义错误 | 修正为 `/\+998/` |
| BUG-09 | C 原型金色小标题对比度约 2.9:1 | 品牌金色直接用于小字号 | 小字号改用 `--gold-ink:#7a5518`（约 5.3:1） |
| BUG-10 | C 首页首屏两个按钮均为招商入口 | 招商优先策略落到 hero | 主按钮改“Наши линейки”，次按钮“Сотрудничество” |
| BUG-11 | `--index` 时页面无 noindex，但 robots 仍全站禁止 | robots 文本写死 | 按 `NOINDEX` 输出 Allow/Sitemap 或 Disallow |
| BUG-12 | 版式脚本默认只跑 A 主题，B/C 未纳入默认回归 | 默认参数写死 `--themes a` | 默认改为 `a,b,c`；完整复跑 552 组合 0 异常 |

**生产模式闸门实跑（2026-11-26）**：用 `--index --origin https://purepawfoods.com` 构建到 `data/temp/prod-build`，在 4176 端口以 `qa-multilingual.mjs --base http://localhost:4176 --origin https://purepawfoods.com --prod` 复检，1,895 项 0 失败；验证后已停止临时服务，未部署。
