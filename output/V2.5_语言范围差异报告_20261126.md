- 新增的营养/喂食/企业资质标签（18 项）在 8 种语言中全部标记为原型草稿，未冒充母语审核。
- `qa-multilingual.mjs` 做字符集与字形检查（中文、阿拉伯文、西里尔文），能发现“语言串台”，不能判断语义是否自然。

## 四、维护成本

| 项目 | 8 语言现状 | 说明 |
| :--- | :--- | :--- |
| 每主题页面 | 13 × 8 = 104 | 四主题共 416 页 |
| 一次文案修改 | 8 份同步 + 2,468 项多语言检查 | 多语言的边际成本主要在这里 |
| 新增产品字段 | 8 语言 × 7 SKU 标签 | 数字只维护一份，标签需八语 |
| 母语审校 | zh/ar/kk/ky/tg 待安排 | en/ru/uz 可用原站文本对照 |
| 关闭某语言 | 改一个 `enabled` 布尔值 | 内容保留，随时可恢复 |

## 五、SEO 价值

| 语言 | 价值 | 说明 |
| :--- | :--- | :--- |
| en / ru | 高 | 原站主力语言，有既有收录基础 |
| uz | 高（本地） | 本地消费者与经销商主语言 |
| zh | 中高 | 原站已有中文内容，保留并优化 |
| ar | 中 | 清真宠物食品潜在出口市场 |
| kk / ky / tg | 低到中 | 与 ru 内容接近，需避免薄页面；保留原站语言但不额外扩写 |

原型相比原站的关键 SEO 改进：独立 URL、每语言独立 title/description、canonical、hreflang、sitemap、语言切换保持当前页面。原站八语同页、无 hreflang，搜索引擎难以判断语言版本。

## 六、资源占用

- 每主题 104 页、约 1.4–1.5 MB；四主题 416 页。
- 构建为纯静态文件，无数据库、无服务器端渲染。
- 八语全量回归：版式 736 组合、多语言 2,468 项、数据 1,925 项；语言越多，QA 时间线性增长。
- 关闭 `kaa`/`tr` 已避免额外 26 页/主题的无效维护。

## 七、站点语言与营销语言分离

- 站点语言：由 `languages.json` 控制页面、菜单、hreflang、sitemap。
- 营销语言：广告、字幕、社媒、客服话术不跟站点语言绑定，应按投放市场单独管理；`marketing.json` 只是原型页内文案，不是营销语言策略。
- 不得因为站点有 8 语，就默认每个市场都投放 8 种语言素材。

## 八、建议

1. 站点语言继续保留原站 8 种，不删除、不合并。
2. 上线前优先完成 zh/ar/kk/ky/tg 的母语审校；未审校语言可先保持与原站相同的公开状态，但不新增扩写内容。
3. 任何未来新增语言（如 kaa/tr）必须经项目所有者批准后才能 `enabled`。
4. 保持“站点语言 ≠ 营销语言”的独立管理。
