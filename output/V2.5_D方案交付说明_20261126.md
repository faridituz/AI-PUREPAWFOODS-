## 二、D 方案统一的视觉与结构

| 维度 | 处理 |
| :--- | :--- |
| 品牌底色 | 沿用 A 的森林绿 `#1e3d2f` 与米色纸感底，全站同一套令牌 |
| 细节语言 | 借用 C 的金铜色 `#b98a3c`，但小字号文字改用加深的 `#74501a`（米色底 6.52:1，通过 WCAG AA） |
| 圆角/间距 | 统一 12px 圆角，介于 A（20px）与 C（6px）之间；段落间距全部来自 `base.css` |
| 按钮 | 实心森林绿主按钮 + 金边次按钮；悬停统一为深金底，不出现三套按钮风格 |
| 图片 | 只使用官网正式 logo（与线上文件一致），未使用 AI 生成包装图或假实拍 |
| 产品展示 | 卡片、规格、营养表、喂食表在所有主题共用同一组件与同一数据源 |
| 多语言 | 8 语言同一导航/切换/表单；阿语 RTL 已单独截图验证 |
| 移动端 | 390px 首页、产品页、品牌页均实机截图；信任条自动换行，表格不溢出 |
| 咨询与招商 | 首页同时保留“咨询表单 + WhatsApp/Email”和“经销商表单”，但分区明确，不混用 |

## 三、D 首页编排（从上到下）

1. 品牌 hero：标题 + 官方 logo + “探索产品系列 / 合作”双入口。
2. 信任条：三条均可在包装/资质文件中核对（保证分析值、乌兹别克斯坦制造、完整成分）。
3. 01 品牌理念：A 式编辑排版。
4. 02 产品系列：猫/狗两张大卡。
5. 03 探索产品系列：7 个 SKU，卡片内可直接展开配料。
6. “每袋都公开什么”：三张证据卡（完整成分与动物性原料占比、保证分析值、喂食表与 7 天过渡）。
7. 如何订购：选择产品 → WhatsApp/电话 → 回复可购买的门店与方式（已删除未确认的配送承诺）。
8. B2B 合作区：合作权益 + 经销商表单。
9. 联系区 + 页脚（含“原型”声明）。
