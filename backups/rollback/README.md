# 正式回滚包存放目录（策略）

本目录独立于 `output/`，不属于任何构建或发布清理范围。

## 规则

1. 回滚包只在此目录或经批准的独立安全备份位置存放，**不放在 `output/release/`**。
2. 普通构建（`node build.mjs`）与发布门禁失败清理均不得删除本目录；`build.mjs` 的删除逻辑被限制在 `output/` 子目录内。
3. 每个包必须有版本号目录（如 `2026-12-01_v1.0.0/`），并附 `SHA256SUMS`：
   - 生成：`sha256sum * > SHA256SUMS`（Windows 可用 `certutil -hashfile <file> SHA256`）
   - 校验：`sha256sum -c SHA256SUMS`
4. 包内不得包含明文密码、API 密钥、`.env`、客户个人数据；仅限静态发布产物。
5. 正式部署前必须做一次实际恢复演练（解压到隔离目录、启动校验、页面抽查），并保留异地/云盘备份。
6. 目前尚未正式部署，本目录只保留本说明，不生成虚假生产回滚包。

## 与门禁的关系

回滚包是上线审批的配套材料，不参与发布门禁判定；门禁失败不会触碰本目录。
